# PCA9685 电机舵机驱动库（@aily-project/lib-pca9685）

基于 I2C 的 PCA9685 16 路 PWM 驱动库，用一颗芯片同时驱动 **4 路直流电机** 与 **8 路舵机**。

## 通道分配

| 用途 | 通道 | 说明 |
| --- | --- | --- |
| 直流电机 M1 | LED0 / LED1 | 正转 / 反转 |
| 直流电机 M2 | LED2 / LED3 | 正转 / 反转 |
| 直流电机 M3 | LED4 / LED5 | 正转 / 反转 |
| 直流电机 M4 | LED6 / LED7 | 正转 / 反转 |
| 舵机 S1 ~ S8 | LED8 ~ LED15 | 每个舵机占用 1 个通道 |

## 硬件连接

```
ESP32 (I2C 主机)                PCA9685
  SDA  ────────────────────────  SDA
  SCL  ────────────────────────  SCL
  3V3  ────────────────────────  VCC
  GND  ────────────────────────  GND   （必须共地！）
  外部电源 +  ─────────────────  V+    （电机/舵机电源，按器件要求，如 5V~12V）
  外部电源 -  ─────────────────  GND   （与 ESP32 GND 相连）
```

> 电机/舵机请使用独立电源供电（V+），不要用开发板 5V 直接带动电机，以免复位或损坏。

## 积木列表

| 积木 | 说明 |
| --- | --- |
| 初始化 PCA9685 | 设置 I2C 地址与 PWM 频率（放在程序开头） |
| PCA9685 自定义 I2C 引脚 | 非默认 I2C 引脚时使用（如 ESP32-S3 的 GPIO47/48） |
| PCA9685 直流电机 %1 速度 %2 | 速度 -100~100，正值正转，负值反转，0 为停止 |
| PCA9685 直流电机 %1 停止 | 停止单个电机 |
| PCA9685 停止所有直流电机 | 紧急停止 M1~M4 |
| PCA9685 舵机 %1 转到角度 %2 ° | 角度 0~180° |
| PCA9685 舵机 %1 脉宽 %2 μs | 直接以脉宽控制，用于校准 |
| PCA9685 设置舵机脉宽范围 | 设置 0°/180° 对应的脉宽 |

## 使用示例

**仅控制直流电机：**

```
初始化 PCA9685 地址 0x40 频率 1000 Hz
直流电机 M1 速度 60
直流电机 M2 速度 60
等待 2 秒
停止所有直流电机
```

**同时控制电机与舵机（频率必须设为 50Hz）：**

```
初始化 PCA9685 地址 0x40 频率 50 Hz
舵机 S1 转到角度 90 °
直流电机 M1 速度 50
等待 1 秒
直流电机 M1 速度 -50
等待 1 秒
停止所有直流电机
```

## 重要说明

1. **PWM 频率是全局的**：PCA9685 的 16 个通道共用同一个 PWM 频率。
   - 同时使用舵机时，频率**必须为 50Hz**（本库默认 50Hz），否则舵机会抖动或无法定位。
   - 仅驱动直流电机时，可把频率提高到 1000Hz 以上，调速更平滑、噪音更小。
   - 若既要高频率驱动电机、又要精确控制舵机，请使用两片 PCA9685（各自设置不同频率与地址）。
2. **I2C 地址**：默认 0x40，可通过模块上的 A0~A5 跳线修改；地址下拉框默认 0x40。
3. **自定义 I2C 引脚**：若开发板默认 I2C 引脚与接线不一致，请添加“PCA9685 自定义 I2C 引脚”积木并选择实际引脚，它会被“初始化 PCA9685”自动读取使用。
4. **停止方式**：本库的停止为“自由停止”（两路输出都关闭），电机因惯性会继续转动一小段距离。
5. **舵机校准**：不同品牌舵机的脉宽范围不同，可用“脉宽范围”积木调整（常见 500~2500μs 或 400~2400μs）。

## 源文件

驱动源码位于 `src/PCA9685/`：

- `PCA9685.h` / `PCA9685.cpp`：独立的轻量 PCA9685 驱动实现（仅依赖 Arduino `Wire` 库）。

寄存器操作参考 PCA9685 数据手册，API 风格参考 Adafruit_PWMServoDriver（未直接复制其源码）。

## 兼容性

支持 Arduino UNO / MEGA、ESP32 系列（含 ESP32-C3 / ESP32-S3）、Arduino UNO R4 等 3.3V / 5V 开发板。
