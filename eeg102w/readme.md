# EEG102W 脑电模组库（@aily-project/lib-eeg102w）

EEG102W 双通道脑电模组的 BLE 客户端库：ESP32 扫描并连接模组（BLE 广播名 `KSEEG102`），读取专注度、放松度、疲劳度、冥想值指标，以及原始 EEG 通道值、电池电量和电极脱落状态。

- **包名 / 版本**：`@aily-project/lib-eeg102w` / 0.0.1
- **来源**：本项目本地库 `local-libraries/@aily-project/lib-eeg102w`
- **许可证**：UNLICENSED（package.json 未声明正式许可证）
- **协议依据**：脑电模组 BLE 通讯协议 V1.0（2026-09-24）

## 支持的板卡与环境

- ESP32（arduino-esp32 3.3.10 测试通过），ESP32 作为 BLE 中心设备
- 模组需 BLE 5.0；无需接线，使用无线连接
- 串口监视器建议 115200，用于查看读到的数据

## 最小用法

1. 在 `setup` 中初始化串口并连接模组：`eeg102w_connect`（超时 10 秒，扫描不到返回未连接）
2. 在 `loop` 中判断 `eeg102w_connected`，然后用 `eeg102w_metric` 等块读取数据并串口打印

指标范围 1~100；原始值 = 原始采样值 ÷ 10000；电量单位为 %；电极脱落为布尔值。

## 已知限制

- 一次只连接一个模组；连接为阻塞调用，未连接时读数为 0
- 库不自动重连；断线后需再次执行连接块
- 真机 BLE 连接与数据尚未验证（无实物模组）；解析逻辑已由板卡编译器在编译期验证
