## Supported Boards

Arduino-compatible boards with digital input pins. Voltage 3.3-5V.

## Description

SEN0715 miniature non-contact liquid level sensor with digital output.

## Quick Start

Put sen0715_init in arduino_setup(), then read sen0715_detected in arduino_loop(). Brown=VCC, Black=OUT, Blue=GND.
