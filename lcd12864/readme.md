# @aily-project/lib-lcd12864

内置字库版 LCD12864（ST7920 控制器，串行接口）积木库。控制器字库含 8192 个 16×16 中文字符与 126 个西文字符；库内置 Unicode→GB2312 映射表（7445 个 GB2312 字符全覆盖），UTF-8 中文直接显示。

- **版本**：0.0.1（本地库，源码位于本项目 `local-libraries/@aily-project/lib-lcd12864`）
- **许可**：UNLICENSED；**适用板卡**：任何支持 Arduino API 数字输出的板卡（含 STM32F103C8、ESP32 等）
- **接线（串行三线）**：LCD 的 CS→自选引脚（如 PB0）、SID→自选引脚（如 PB1）、SCLK→自选引脚（如 PB10）；模块 PSB 需接地选择串行模式，VCC/GND 按模块要求供电
- **最小用法**：启动时执行「初始化 LCD12864（CS/SID/SCLK）」，然后「LCD 显示文本」即可输出中文；文本中的换行符（`\n`、`\r\n`）会自动换到下一行

常用开关：自动换行（满屏自动向上滚动）、满屏时停止显示、半角字符自动补空格、文本编码（UTF-8/GB2312）、反色显示、绘图模式。详细积木契约见 README_AI.md。
