## Supported Boards

ESP32 boards. Resolution (default 104×212) and pins (default: linkbit wiring) are block inputs. When the board's `displayConfig` has `model` `epd_cz04`, toolbox blocks start with its resolution and pins.

## Description

2.13" 104x212 four-grey e-paper (CZ04) with drawing, Chinese text and weather icons

## Quick Start

1. Enable `@aily-project/lib-epd-cz04` in Aily Blockly.
2. Add the library blocks, initialize hardware in `arduino_setup()`, then use read/write blocks in `arduino_loop()`.
