# STOS 商用控制平台库

本地积木库 `@aily-project/lib-stos` v0.0.1，为 STM32F103C8 提供 0.96 寸 ST7735S 屏（软件SPI）、SD 卡槽（软件SPI + FAT16/32）、4x4 矩阵键盘、游戏摇杆、扬声器的初始化与"STOS"桌面系统事件积木（桌面/开始菜单/窗口按钮/任务栏校准、SD 插入、S1~S16 按键、按住连发、摇杆朝向、关屏唤醒等）。

## 最小接线（示例程序所用引脚）

| 外设 | 引脚 |
| --- | --- |
| 屏幕 ST7735S | SCL=PA2 SDA=PA3 RES=PA4 DC=PA5 CS=PA6 BLK=PA7 |
| SD 卡槽 | CS=PA8 SCK=PB3 MOSI=PB4 MISO=PB5 |
| 矩阵键盘 | 列C1~C4=PB10~PB13 行S1~S4=PB14,PB15,PB6,PB7 |
| 摇杆 | VRX=PA0 VRY=PA1 SW=PB9 |
| 扬声器 | 正极=PB8（负极接GND） |

## 使用

setup 中依次放入 5 个初始化积木；loop 中放入事件积木并在其内部接动作积木（详见 README_AI 示例）。所有积木通过全局单例 `stos` 工作，无需创建变量。

- 校准 = 用摇杆把"鼠标圆点"移到目标热区后按下摇杆 SW。
- "按住矩阵键盘"事件积木（`stos_when_key_held`）在按住期间连发：每 10ms 帧至多一次，与摇杆同速（≈100px/s 匀速），松开即停；示例程序用它实现按住 S4/S8/S12/S16 持续移动鼠标圆点。
- 任务栏最左 START 按钮内部处理（切换开始菜单）。
- 硬件行为尚未在实机上验证。
