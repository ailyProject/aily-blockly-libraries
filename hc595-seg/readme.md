# lib-hc595-seg（595 数码管库）

两片 74HC595 级联驱动的多位数码管 aily Blockly 库。支持自选 SDI/SCLK/LOAD 三个引脚、共阴/共阳接法，按位选择数码管并设置段码显示。

- 包名：`@aily-project/lib-hc595-seg`（本地库，版本 0.0.1，license: UNLICENSED）
- 适用：提供 `pinMode`/`digitalWrite`/`delayMicroseconds` Arduino API 的板卡；已在 EasyVoice 1306 Dev（CI1306）上编译通过

## 接线

| 595 信号 | 引脚 |
| --- | --- |
| SDI（串行数据，DS/14 脚） | 自选数字引脚 |
| SCLK（移位时钟，SH_CP/11 脚） | 自选数字引脚 |
| LOAD（锁存时钟，ST_CP/12 脚） | 自选数字引脚 |

要求：首级 595 输出段码，其 Q7'(9 脚) 级联到末级 595（输出位选）的 DS。

## 使用

1. setup 中放「初始化595数码管」积木，选择三个引脚和共阴/共阳。
2. 用「设置第 N 位 显示段码」选择第几位并给定段码（0~255，共阴逻辑：a~g 对应 bit0~bit6，dp=bit7），立即锁存点亮该位。
3. 「字符的段码」输出积木可直接返回 0-9/A-F/H 等字符的段码，接入段码输入。

## 限制

- 一次锁存只点亮一位；多位同显需在 loop 中轮流设置各位形成扫描。
- 发送顺序固定为：先位选字节、后段码字节（MSB 在前）；共阳接法时驱动自动对位选与段码取反（低电平有效）。
- 硬件点亮效果未在实物上验证（见 README_AI 备注）。
