## Supported Boards

Arduino AVR boards such as Nano and Uno (ATmega328P).

## Description

Otto DIY V9 blocks for a four-servo walking robot, ultrasonic distance, sound and LED matrix control.

## Quick Start

Use standard wiring: servos D2/D3/D4/D5, buzzer D13, ultrasonic Trig D8 and Echo D9. Initialize Otto in setup before using motion or sensor blocks. Matrix wiring is DIN=A3, CS=A2, CLK=A1; initialize it before displaying a face.
