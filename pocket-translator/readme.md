# @aily-project/lib-pocket-translator

口袋翻译机：按住按键用 INMP441 麦克风录音（最长 10 秒），松开后把 WAV 上传到硅基流动（SiliconFlow）语音识别接口，再把识别到的中文通过硅基流动对话模型翻译成英文，屏幕上方显示中文、下方显示对应英文（16×16 点阵中文字库，ST7789），最后用硅基流动语音合成把英文朗读出来（MAX98357A 功放 I2S 直推）。

- 包名 / 版本：`@aily-project/lib-pocket-translator` 0.0.1（项目本地库 `local-libraries/`）
- 适用环境：ESP32-S3 + TFT_eSPI + ESP_I2S（Arduino-ESP32 3.3.x）
- 许可证：UNLICENSED（教学项目内部使用）

## 接线

| 器件 | 信号 | GPIO |
| ---- | ---- | ---- |
| 按键 1 / 按键 2 | 内部上拉，低电平有效 | 38 / 39 |
| INMP441 | WS / SCK / SD（L/R 接地=左声道，3.3V） | 4 / 5 / 6 |
| MAX98357A 功放 | BCLK / LRC / DIN（VIN→5V，喇叭接 +/−） | 15 / 16 / 7 |
| ST7789 240×240 | MOSI(SDA) / SCLK(SCL) / CS / DC / RST / BLK | 47 / 21 / 41 / 40 / 45 / 42 |

## 最小用法

1. 让 `tftespi_setup` 先初始化屏幕，再放 `pt_init`（最后三个下拉框填功放的 BCLK、LRC、DIN）。
2. `loop` 中用 `有按键刚按下(消抖)` 触发 `按住录音`，随后 `硅基流动语音识别`；识别成功后调用 `硅基流动翻译 中文→英文`，再用 `屏幕写文字(含中文)` 先画中文（上方）、后画英文（下方）。
3. 最后调用 `硅基流动语音朗读英文` 播报译文：模型填 `fnlp/MOSS-TTSD-v0.5`、音色填 `fnlp/MOSS-TTSD-v0.5:anna`；`最近一次朗读成功` 可判断是否播放完成，失败原因用 `最近一次错误信息` 显示。
4. 音量用 `设置喇叭音量` 调小（0–100，建议 30–60）。MAX98357A 的 GAIN 是硬件固定的，所以该积木是在软件层缩放 PCM；本工程默认 40%。

完整积木图见 IDE 工具箱的“口袋翻译机”分类。识别需要联网，请替换 WiFi 名称/密码与硅基流动 API Key 占位符。
