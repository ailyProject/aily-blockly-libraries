# LD2410C 雷达帧存储库

通过软串口接收 LD2410C 毫米波雷达模块的一帧数据（23 字节）并存储，供图形程序逐字节读取。

## Supported Boards

Arduino UNO 等 AVR 板（依赖 Arduino 自带 SoftwareSerial）

## Description

按帧头 244、243、242、241 对齐、按帧尾 248、247、246、245 定界，从软串口组装可变长帧并存储最新一帧有效数据（基本模式 23 字节、工程模式最长 45 字节）；提供按字节读取、实际长度查询与新帧判断图形块，并可直接解析目标状态、运动/静止目标距离与能量、探测距离、距离门数量与门能量、光敏值等字段。

## Quick Start

1. 接线：模块 TX → 开发板 RX 引脚（默认 2），模块 RX → 开发板 TX 引脚（默认 3，5V 逻辑建议分压），共地，按模块规格供电。
2. 用「连接软串口」块选择与模块一致的波特率（出厂 256000；软串口高波特率易出错，可先把模块改为 115200 或更低）。
3. 循环中反复调用「读取并存储一帧数据」，用「收到新帧？」判断后，以「数据区的第 N 字节」读取存储内容（帧长可变，「帧总字节数」返回实际值 23~45），或直接用「目标状态」「运动目标距离/能量」等解析块取值。
4. 连接 2 个及以上模块：每个模块单独「连接软串口」（不同对象名、不同 RX/TX 引脚），循环中用「自动轮询所有雷达」代替逐个读取（同一时刻仅一个软串口可接收，收到完整帧或 500ms 超时自动切换）。
